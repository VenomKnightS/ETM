Fit set

A set is fits you fly together — e.g. two Retributions and a Kirin for an abyssal. Every fit in a set keeps the same name and the same notes, and each still exports to EVE as its own fit. Fits named like "… x3" are grouped for you automatically.

🖥 PC link — throw fits to your PC clipboard
  1. On your Windows PC, run EVE Tiles Mobile PC Link (etm_pc_link.py). It shows a code like ABCD-EFGH-JK.
  2. Type that code here and tap Link. A test popup appears on the PC.
  3. To sync plans/fits/Char Sets with this app in your PC's browser too, enter the same code there (💾 → 🔗).
  4. Then use 🖥 Send to PC on any fit, or swipe the ⇧ strip on a fit up to throw it. On the PC it lands on the clipboard: Ctrl+V into Pyfa or EVE's fitting window (Import from clipboard).
…or, if you set a Password in the PC helper:

Fits travel through the free ntfy.sh relay, compressed and encrypted with a key made from your code, so the relay can't read them. The code stays on this device and isn't included in backups.

Quick add — type, paste or dictate 🎤

Commas between characters, semicolon between accounts — the first name of each account is its main. Empty slots: leave blank or say/type x. Works with voice typing: say "comma" and "semicolon" (or "next account"). Names are matched to EVE, so capitals don't matter. One name per line with blank lines between accounts works too.

Backup & restore

Your data lives in this browser only. To move it to another device (phone ↔ PC), download a backup here and restore it there.

Includes: tracked pilots, plans, Char Sets, fits and tags, and settings. Not included: EVE logins (log in again on each device, for safety) and downloaded killmails (they re-download when you track a pilot).
